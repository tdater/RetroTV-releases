# RetroTV

Every retro console on your Android TV, with no emulators to install. RetroTV is a TV browser built for
in-browser emulation sites. It gives the remote a pointer, passes controllers straight to the game, blocks
ads without breaking anything, and can install sites as their own TV apps. It also has a userscript
manager and one-tap emulator downloads.

## Download

**[Get the latest APK](https://github.com/tdater/RetroTV-releases/releases/latest)** (under *Assets*).

**[See everything it does](https://tdater.github.io/RetroTV-releases/)**

## Install

1. On the TV, install **Downloader** (AFTVnews) from the Play Store or Amazon Appstore.
2. Use it to download the APK from the latest release.
3. Allow it to install unknown apps when asked, then press **Install**.

Requires Android 7.0 or newer (Android TV, Google TV, Fire TV).
